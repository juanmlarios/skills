# Working agreements

- Follow applicable repository and directory instructions. Keep changes within the requested scope and preserve unrelated user changes.
- Prefer the smallest maintainable solution consistent with the codebase.
- Use tools configured and available in this session. When GitNexus has a usable index, use it for dependency, execution-flow and shared-behavior impact questions; confirm important findings in source.
- Keep searches and output focused. Preserve full evidence when needed and distinguish observed facts from assumptions.
- Use current documentation when the answer depends on information that may have changed.
- For implementation requests, complete the scoped change and relevant validation. For reviews or recommendations, report findings without changing code or configuration.
- Ask before destructive changes, production operations, adding production dependencies or publishing changes unless explicitly authorized.
- Finish concisely with the result, changed file paths, validation performed and remaining blockers.
